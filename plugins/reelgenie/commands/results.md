Show how the person's recent posts did, using the "Results" section of the `reelgenie` skill.

Scope, if given: $ARGUMENTS

Report only the numbers ReelGenie returns, say when they were last synced, and never promise views, followers or growth. If nothing has gone out yet, say so and offer to check a saved post instead.

If no ReelGenie tools are available, the plugin is not signed in yet: follow "If ReelGenie is not answering" in the `get-started` skill (run `/mcp`, choose `plugin:reelgenie:reelgenie`, sign in) before anything else.
